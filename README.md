# rmalump.github.io

Portada de las aplicaciones web de R.M.P. publicadas en GitHub Pages (`https://rmalump.github.io/`).

- `index.html`: enlaces a todas las aplicaciones (cada una vive en su repositorio y en su ruta: `/GPapers/`, `/SupuestosC1/`…).
- `privacidad.html`: política de privacidad común de todas las aplicaciones (cada app con Google Drive tiene además la suya).
- `google415a4e3d6145dca0.html`: verificación del dominio `https://rmalump.github.io/` en Google Search Console (necesaria para verificar la marca de las apps que usan Google Drive). **No borrar.**
